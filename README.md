# 🌸 Moodie — ton petit jardin d'humeur

Application de journal d'humeur avec un jardin virtuel, réalisée avec React, TypeScript et Vite.

## Démarrer

```bash
npm install
npm run dev
```

Ouvrir l'adresse locale fournie par Vite, généralement http://localhost:5173.

## Fonctionnalités

Journal quotidien, fleurs selon les humeurs, calendrier, statistiques et stockage local des données.
